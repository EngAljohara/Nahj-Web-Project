# Nahj | نهج

A collaborative educational website exploring the history of the Saudi state, from the First Saudi State through the Second Saudi State and the modern Kingdom of Saudi Arabia.

## Overview

Nahj presents historical content through Arabic-language web pages, images, and navigation between historical periods. This is a **team project**; individual contributions should be described accurately when confirmed.

## Technologies

- HTML5 and CSS3
- JavaScript (embedded in the pages)
- PHP (language preference handler)
- Google Fonts

## Pages

- `Home.html` — main landing page
- `index.html` — First Saudi State
- `index2.html` — Second Saudi State
- `index3.html` — Kingdom of Saudi Arabia
- `setlang.php` — stores Arabic/English language preference in a cookie and session

## Running locally

For the full experience including PHP language preference handling, use a local PHP server:

```bash
php -S localhost:8000
```

Then visit `http://localhost:8000/Home.html`.

You can open `Home.html` directly for a basic static preview, but PHP links will not work without a PHP server. **GitHub Pages does not execute PHP.** The site has not been independently tested as part of this packaging process.
